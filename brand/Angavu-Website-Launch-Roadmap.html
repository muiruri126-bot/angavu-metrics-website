Phase 1 Content Completion

Priority: HIGHEST — This is the #1 blocker to going live.

#TaskDetails
1.1 Finalize Logo Pick one of the 3 concepts (Clarity Prism, Impact Horizon, or Connected Insight). Produce final SVG, PNG, and favicon files.
1.2 Team Page Replace placeholder cards with real names, titles, bios, professional headshots, and credentials for all team members.
1.3 Case Studies (Projects Page) Write 3–5 real case studies including sector, client type, methodology used, and measurable outcomes. Replace the "Coming Soon" message.
1.4 Real Testimonials Replace the 3 example quotes on the homepage with actual client testimonials (including name, organization, and role).
1.5 Partner / Client Logos Replace placeholder text in the partners strip with actual organization logos (PNG or SVG, consistent sizing).
1.6 Resources Section Publish at least 2–3 real items: a learning brief, a policy brief, and/or a framework document to populate the Resources page.
1.7 Social Media Profiles Create LinkedIn company page and Twitter/X account. Update all footer links across every page (currently pointing to #).

Phase 2 Technical Infrastructure

Set up the backend systems needed to run the site professionally.

#TaskDetails
2.1 Custom Domain Purchase angavumetrics.com (or .co.ke) and configure DNS records.
2.2 SSL Certificate Ensure HTTPS is active. Free via GitHub Pages, Netlify, or Cloudflare.
2.3 Hosting Setup Deploy to GitHub Pages (from website/ folder) or Netlify. Create .github/workflows/deploy.yml for automated deployments.
2.4 Email Setup Configure info@angavumetrics.com and tors@angavumetrics.com via Google Workspace, Zoho, or similar provider.
2.5 Formspree Verification Verify the contact form endpoint (xpwdjgvb) works on the production domain. Consider upgrading to remove Formspree branding.
2.6 Newsletter Backend Connect the newsletter signup form to Mailchimp, Brevo (Sendinblue), or ConvertKit.
2.7 Google Analytics Verify GTM container GTM-WBJGB5GM is active and all tags are firing correctly on the production domain.

Phase 3 SEO & Discoverability

Ensure search engines can find, index, and properly display your site.

#TaskDetails
3.1 Create robots.txt Allow all crawlers, point to sitemap location. Place in the root of the website/ folder.
3.2 Create sitemap.xml List all public pages with priority weights and last-modified dates.
3.3 Create 404.html Custom "Page Not Found" error page matching the Angavu brand and providing navigation back to key pages.
3.4 Favicon & App Icons Add favicon.ico, apple-touch-icon, and Open Graph share image from the final logo.
3.5 Google Search Console Register site, verify ownership via DNS or meta tag, and submit sitemap.xml.
3.6 Google Business Profile Register "Angavu Metrics" with Nairobi address for local search visibility in Kenya.
3.7 Verify Structured Data Run Google's Rich Results Test on the JSON-LD schema already embedded in index.html. Fix any warnings.

Phase 4 Quality Assurance & Testing

Comprehensive testing before going public.

#TaskDetails
4.1 Cross-Browser Testing Test on Chrome, Firefox, Safari, and Edge — both desktop and mobile versions.
4.2 Real Device Testing Test on actual Android and iOS devices (not just browser responsive mode).
4.3 Lighthouse Audit Run Google Lighthouse. Target 90+ scores on Performance, Accessibility, SEO, and Best Practices.
4.4 Broken Link Check Scan all pages for broken links, missing images, and dead # anchor references.
4.5 Form Testing Submit test entries through the contact form and TOR email. Confirm delivery to the correct inboxes.
4.6 Content Proofread Final grammar, spelling, and factual accuracy review across all pages.
4.7 Accessibility Audit Run axe DevTools or WAVE. Fix any remaining WCAG 2.1 Level AA issues.
4.8 Load Testing Basic load test to ensure hosting can handle traffic spikes after launch announcements.

Phase 5 Pre-Launch Preparation

Final checks before flipping the switch.

#TaskDetails
5.1 Legal Review Have the Privacy Policy and Terms of Use reviewed by a legal advisor for compliance with the Kenya Data Protection Act (2019).
5.2 Version Control Backup Ensure all code is committed and pushed to the GitHub main branch. Tag the release (e.g., v1.0.0).
5.3 Uptime Monitoring Set up UptimeRobot (or similar) for downtime alerts via email/SMS.
5.4 Error Tracking Consider adding Sentry (free tier) for JavaScript error monitoring in production.
5.5 Create .gitignore Add standard ignores: .DS_Store, node_modules/, *.log, IDE files, etc.
5.6 Staging Review Share the staging URL with 3–5 trusted colleagues or partners for feedback. Collect and address their input.

Phase 6 Launch Day 🚀

Go live and announce to the world.

#TaskDetails
6.1 Point DNS to Production Switch the domain from parking/staging to the live hosting provider.
6.2 Verify HTTPS Confirm SSL certificate is working correctly on all pages and subpages.
6.3 Submit Sitemap Push sitemap.xml to Google Search Console to trigger indexing.
6.4 LinkedIn Announcement Publish a launch post on the Angavu Metrics LinkedIn company page with a compelling message.
6.5 Twitter/X Announcement Launch tweet with the tagline "Clarity. Evidence. Impact." and a link to the website.
6.6 Email Signatures Add angavumetrics.com to all team members' email signatures.
6.7 Network Outreach Email key contacts, existing partners, and University of Nairobi collaborators with the launch announcement.

Phase 7 Post-Launch Growth (Ongoing)

Continuous improvement and content marketing after going live.

#TaskCadence
7.1 Blog / Insights Section Build the blog page. Publish 1–2 thought leadership articles per month on M&E topics, policy analysis, or sector trends.
7.2 New Case Studies Add new case studies as projects are completed. Target 2–3 new entries per quarter.
7.3 SEO Monitoring Monthly — Track keyword rankings for terms like "M&E consultancy Kenya", "impact evaluation East Africa", "MEAL systems".
7.4 Analytics Review Monthly — Review traffic sources, top pages, bounce rates, and form submission conversion rates.
7.5 Content Freshness Quarterly — Keep the Resources section updated with new briefs, tools, and frameworks.
7.6 Client Portal Future — Consider a password-protected area for sharing client deliverables and project dashboards.
7.7 Multi-Language Support Future — Consider Swahili or French versions for broader regional reach in East Africa.

Recommended Timeline

6-Week Sprint to Launch

Week 1–2 Phase 1 — Content completion (team bios, case studies, testimonials, logo finalization). This is the #1 blocker.
Week 3 Phase 2 — Technical infrastructure (domain purchase, hosting setup, email configuration).
Week 4 Phase 3 + 4 — SEO setup and QA testing (run in parallel).
Week 5 Phase 5 — Pre-launch preparation, staging review with trusted colleagues, final fixes.
Week 6 Phase 6 — GO LIVE! DNS switch, announcements, outreach.
Ongoing Phase 7 — Post-launch growth, blog, case studies, SEO monitoring.

Bottom Line

Your website's technical foundation is strong. The critical path to launch is real content (team bios, case studies, testimonials, finalized logo) and infrastructure (domain + hosting + email). Once those are in place, you're days away from going public.
